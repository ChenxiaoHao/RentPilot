# RentPilot 用户端 MVP · 2026-10-28

## 本轮授权与方向

用户授权直接完成全端页面优化，不再要求沿用 Stitch 布局。保留 Vue 3、TypeScript、Capacitor、黑白灰与底部胶囊导航；增加实际可操作的交互，删去重复解释。不开发后端或管理端，不改原始 CSV、设计资料和依赖。

使用正式安装的 design-taste-frontend v2.1.5，走 App screens 分支。抽取 achromatic-ledger，seed 1377920872。将桌面开放式画布适配为手机单列；品牌限制覆盖图表色，全部使用中性色；消费者 App 使用 20px 圆角和 44px 以上触控区域。保留现有 Manrope，中文优先系统无衬线字体。无营销入场动画和玻璃效果。

产品辨识点：RentPilot 导航标记、上海工作地与通勤、月度生活账本、可切换的一天时间线。照片使用项目已有示意素材，不下载竞品素材。

## 页面回答的问题

| 页面 | 优先回答 | 主要操作 |
|---|---|---|
| 聊天首页 / 多轮对话 | 我想怎样住？ | 条件编辑、快捷需求、发送、图片预览、归档与恢复对话 |
| 找房 | 哪套房适合当前条件？ | 搜索、筛选、排序、地图/列表、收藏 |
| 居住方案 | 时间、预算、舒适度怎样取舍？ | 横向切换、保存、成本明细、进入对比 |
| 方案详情 | 这套方案具体意味着什么？ | 房源、生活模拟、展开看房要点 |
| LifeSim | 搬进去以后的一天怎样？ | 场景、时间节点、工作日数量、确认场景 |
| 双方案对比 | 两套方案究竟差多少？ | 换方案、交换、选择偏好和采用 |
| 房源详情 | 房子和费用是否合适？ | 放大照片、收藏、费用、拟定本地看房计划 |
| 我的 | 我之前保存了什么？ | 编辑昵称、收藏、对话、看房计划、版本 |
| 居住偏好 | 我更在意什么？ | 三项权重、组合预设、即时预览、确认 |
| 历史版本 | 每次调整改变了什么？ | 选择版本、差异、快照、恢复确认 |
| 协商 / 生成 / 空结果 | 下一步怎样继续？ | 明确取舍、取消/查看、仅调整一项条件 |

## 参考与边界

参考 [自如官方 App 介绍](https://zhuanti.ziroom.com/zhuanti/app/open/index.html) 的位置找房、特色筛选和看房路径，将常用操作前置。贝壳页面受访问限制，未据此声称评审过其当前 App。

Mock 必须清楚但不过度重复：页头统一“演示”入口、房源“模拟房源”标记、预约明确为本地看房计划；详细限制放入说明或相关操作弹层。不会冒充真实 AI、实时地图或真实预约。
