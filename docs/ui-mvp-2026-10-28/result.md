## 完成范围

9 个核心页面与 7 组交互状态均保留可访问，覆盖 13 个页面组件。本轮重新设计了首页、对话、找房、方案、详情、LifeSim、对比、个人中心、偏好与版本等界面，不再要求贴合 Stitch。统一白色画布、黑色主操作、灰色辅助面、中文字号和胶囊导航；减少重复说明和嵌套卡片。

| 流程 | 可操作内容 |
|---|---|
| 聊天 | 条件编辑、多行输入、快捷填入、图片本地预览、复制/再次编辑、归档与恢复、返回最新 |
| 找房 | 关键词、区域/租金/户型/地铁筛选、排序、收藏、地图/列表、展开列表；详情返回保留条件 |
| 方案 | 横向滑动、按钮/键盘切换、保存、生活账本、详情、模拟与对比 |
| 房源 | 照片放大、配置、通勤示意、看房检查项、押付费用试算、日期/时段计划、咨询问题转入对话 |
| LifeSim | 方案、四种生活场景、展开时间节点、工作日增减、月度通勤总量、确认核心场景 |
| 对比与版本 | 选择/交换两套方案、显示真实算术差额、选择取舍、历史快照、差异、恢复确认 |
| 我的 | 编辑昵称、收藏类型、历史对话、查看/取消本地看房计划、通知偏好 |
