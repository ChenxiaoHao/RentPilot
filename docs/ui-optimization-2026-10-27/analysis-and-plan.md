## 按优先级的结论

### P1 可读性和触控

多数页存在8–11px辅助信息，聊天输入12px、发送34px、地图工具35px；小字与浅灰叠加使中文辨识费力。提高正文至14–15px、辅助至12–13px，标题20–28px（首页28–32px例外），触控至少44px；全局与scoped样式一起整理。

### P1 完整操作反馈

地图筛选后所选房源可能已不在结果中；图片不能放大；咨询/预约仅toast；协商选项缺radio语义。保留业务数据与计算，补齐筛选联动、当前选中反馈、可关闭演示弹层、确认与成功反馈，不连接或冒充真实服务。

### P2 信息层级与密度

首页留白分配偏松、提示偏小；方案卡片和对比标签难读；偏好与历史过密；个人中心英文页头及细小统计破坏统一。保持原有模块顺序、原图、黑白灰及胶囊导航，建立统一留白、圆角、标题和标签层级。长页继续自然滚动。

### P2 增加现有流程内的交互

- 对话：首页需求快捷填入，Enter换行，发送反馈，参考图片本地预览与移除；不调用图片理解。
- 地图：筛选计数、结果重置、稳定点位和卡片联动。
- 方案：横滑和显式前后切换、选中页码、收藏反馈。
- 偏好：滑块与预设选择即时预览、未应用状态、重置、确认应用。
- LifeSim：场景选择、时间轴展开/收起和切换反馈；仍为本地模拟。
- 对比/历史：差异强调、版本选择和恢复确认；保留既有版本语义。
- 房源：示意图放大，演示预约/咨询说明弹层；明确无真实提交。
- 个人/空态/生成/协商：本地设置反馈、可继续操作的空态、分阶段加载、可键盘选择的协商卡片。

### 已验证有效的处理

Android软键盘出现后，视口521px、输入和发送均在可见区，底部导航隐藏；不认定已有遮挡，不重写有效原生适配。长页全屏截图中固定导航位于首个视口底部，不等于永久内容遮挡，最终以滚到底后的空间验证。
