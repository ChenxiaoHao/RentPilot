# 普通租房用户端闭环

用户要求：先完成普通租房 App 功能，Agent 后置。延续用户此前直接实施、不反复确认的授权。本轮交付开发/演示可运行的用户端闭环，不把模拟房源当真实供应。

## 范围

1. 完整数据库房源详情、室内示意图、设施三态、押付与首次资金说明、同区域房源、有效坐标打开官方高德位置页；缺失坐标不给假点位。不实现无密钥的伪高德SDK。
2. 用户名密码注册/登录、退出、昵称维护。浏览免登录，收藏和服务端个人记录需登录。BCrypt密码哈希；安全随机会话仅存哈希，Bearer鉴权，30天有效；不提供假短信或找回功能。
3. 收藏添加/取消/分页、最近浏览记录/清空，按用户隔离，重复操作幂等；收藏、历史、计划引用真实存在的模拟房源编号。
4. 服务端看房计划：PLANNED/CANCELLED/COMPLETED，创建、修改日期时段、取消、标记已看；同用户同房源仅一个待看计划。日期为上海时区今天至60天内，固定三时段；不是向经纪人提交或确认预约。
5. 新个人中心展示真实账号/收藏/最近浏览/待看计数，编辑昵称与退出；旧示例资料和AI页面保留为演示入口，不与新记录混合。
6. 主导航为找房、收藏、计划、我的，保持胶囊外形及黑白灰。默认入口为房源列表，AI/方案旧路由保留。本轮不开发Agent、管理后台、真实聊天/合同/支付/短信。

## 数据和接口

Flyway V2新增 member_account/member_session/favorite_listing/browsing_history/viewing_plan，不修改V1或原CSV。H2本地持久化，兼容预留PostgreSQL配置。

- POST /api/auth/register、/login、/logout。
- GET/PATCH /api/me；返回本人资料和收藏/历史/待看计数。
- GET /api/me/favorites；PUT/DELETE /api/me/favorites/{listingId}。
- GET /api/me/history；PUT /api/me/history/{listingId}；DELETE /api/me/history。
- GET/POST /api/me/viewings；PUT /api/me/viewings/{id}；PATCH /api/me/viewings/{id}/status。
- 私有分页从0起，默认20、上限50。私有对象始终由Bearer解析用户，不能用请求userId越权；他人计划返回404，缺少/失效会话返回401。
- 个人房源页 items 为 {listing,recordedAt}；计划包含 listing、date、slot、status、id，count等基于后端实际表。

所有写操作事务化；每用户写入锁防重复收藏/历史/待看计划；外键验证存在性。昵称和表单参数校验，日期/状态转换校验；400与404/409/401明确区分，不暴露SQL或凭据。Token只经请求头传递，不记录密码/会话原文。

前端新增独立member状态和auth存储，不清除原 rentpilot-demo-v1，不自动迁移或冒充原六套示例为新房源。账号切换/退出清除内存私有数据，迟到请求不能覆盖新账号。仅会话凭据保存在当前设备，无密码落盘；生产需HTTPS与进一步部署安全验证。

## 验收

注册登录→列表→详情→收藏→收藏列表→计划→修改/取消→最近浏览→我的→刷新/重启保留；另一个用户看不到前者数据。非法ID/日期/状态、重复提交、过期令牌、无网络和迟到响应均有测试。费用可按原付款方式复算。320/360/402/480、安全区域和键盘正常；构建、现有及新增测试、同步、Gradle、模拟器运行均验证。真实短信、经纪人确认、线上签约支付和地图SDK明确留待资源接入。
