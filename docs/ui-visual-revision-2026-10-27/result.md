# RentPilot 二次视觉优化

用户反馈上一轮变化不明显。本轮重新对照 Stitch、原始界面和上一轮截图，调整页面主要构图；延续 Vue 3、TypeScript、Capacitor、黑白灰和悬浮胶囊导航。

- 聊天首页以浅灰欢迎区和快捷输入区建立层级；已有对话中的偏好补充重新组织为清晰的操作区。导航的当前页面使用黑色选中态。
- 方案列表突出社区大图和租金、通勤数据，压缩嵌套卡片与空隙。在 402×874 首屏，方案详情按钮底部为 y=781，导航顶部为 y=792，两者没有重叠。
- 地图强化地图与结果抽屉的分层、筛选选中态和当前房源状态；小屏筛选可横向滑动。
- 个人中心将身份、版本、收藏和对话统计组织为一组；LifeSim 使用连续时间线和更清楚的指标分隔。
- 所有数据和操作继续标注 Mock；现有页面、交互、本地数据和用户聊天记录保留。

## 验证

- `npm run build`：成功；`npm test`：5 项状态测试通过。
- 24 项浏览器交互测试通过；最后微调筛选文字与个人中心文案后，12 项相关流程再次通过。320/360/402/480 页面范围检查无水平溢出。
- 呈现 37 张截图供对照，最后针对首页、方案、地图和个人中心另做生产构建截图检查。
- `design-taste-frontend` 的 App 模式对 390×844 首页生产构建检查为 **0 FAIL / 0 WARN**，并已查看生成截图；这是首页度量，不代表其他页面自动检查均零警告。
- Capacitor Android 同步与 Gradle `assembleDebug` 成功；新 APK SHA-256：`9EC965A2C96A9E43E95D2B1D9EB6271B69336AEAEF9CD88AE50F184742685B4D`。
- 新 APK 已使用 `install -r` 安装到 Pixel 8 API 35 模拟器并启动；已有对话仍在，输入框与发送按钮在软键盘显示时保持可见，导航自动隐藏。
- 仍未在实体设备验证；地图、房源、预约和 AI 仍为本地演示，没有接入真实服务。
