# 普通租房 MVP 交付记录

日期：2026-10-28。按用户要求优先完成普通租房流程，暂不开发 Agent。保持 Vue 3 + TypeScript + Capacitor、黑白灰和底部胶囊导航，不开发管理端，不修改原始 CSV 或设计素材。

## 当前可操作流程

默认首页进入找房，主导航调整为**找房 / 收藏 / 计划 / 我的**。

1. **找房与详情**：1500 条模拟房源真实查询后端；搜索、筛选、排序、20 条分页。详情展示示意照片、户型、设施三态、位置、租金、押金和付款方式；按原付款方式计算首期租金与押金，未知物业费周期保留说明。返回列表保留筛选、已加载数量和位置。
2. **账户**：用户名密码注册、登录、显示密码、登录后返回原操作；编辑昵称与退出。密码 BCrypt，随机会话在数据库只存哈希；30 天会话，失效后要求重新登录。
3. **收藏**：列表或详情添加/取消，账户收藏分页；删除后重新整理分页，避免漏项。刷新及后端重启保留。
4. **浏览记录**：登录后浏览详情自动记录最近时间，列表分页，确认后清空，不影响收藏。
5. **个人看房计划**：选择日期和时段，创建/修改时间、取消、标记已看，按待看/已取消/已看查看。当天过期时段不可选，同账户同房源只保留一条待看计划，重复请求不生成重复项。
6. **我的**：显示当前账户真实收藏、浏览和待看数量，资料与资源入口。另一账户看不到前一账户的记录。

有有效 GCJ-02 坐标的详情提供外部高德位置链接；14 条缺坐标记录不生成假点位。它是小区参考位置，未集成高德 SDK 或工作地路线计算。[高德 URI 官方说明](https://lbs.amap.com/api/uri-api/gettingstarted)。

六张 Pexels 室内照片继续本地复用，明确“示意图 / 非该房源实拍”，[来源许可](../../frontend/public/assets/catalog/README.md) 保留。房源虽然由真实数据库服务返回，内容仍全部是模拟数据。

## 数据与会话保护

Flyway V2 新增账户、会话、收藏、历史和计划表，原 V1 与原 CSV 不改。私有请求使用 Bearer，后端从会话确定用户，不能指定他人用户编号；他人计划返回 404。账户写锁与唯一约束处理并发重复请求。

前端新会话键为 `rentpilot-account-v1`，不存密码。旧 `rentpilot-demo-v1` 不清空、也不自动把旧示例转换为账户资源。跨标签切换账号会关闭旧确认框/计划表单，旧请求不能覆盖新账户或操作新用户。仅会话变化跨标签同步，同账户其他标签的资源变化需重新进入或刷新读取。

源代码已备份为本目录 `source-before.zip`，迁移前停止经确认属于本项目的后端进程，再备份原本地库。数据库备份只留本机、不提交。原 CSV、说明及前端 package/lock 共 4 个保护文件 SHA-256 全部一致，见 `protected-before.json` 和 `protected-after.json`。

## 下一步与未接入部分

普通租房 MVP 的核心操作已完成。进一步接近真实租房产品，建议依次补充：实体 Android 设备验收 → 高德 SDK 的地图找房与定位 → 经纪人/房东联系渠道及预约确认流程。真实房源、照片与联系信息需要合法且可核验的数据来源。
