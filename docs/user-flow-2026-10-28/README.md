# RentPilot 用户端调整说明

## 使用流程

- 打开 App 后进入 AI 对话演示。底部依次为 AI、找房、联系和我的；收藏、居住方案和原有看房记录可在“我的”查看。
- 在“找房”中可按上海行政区、街镇、地铁线路和站点筛选。站点由后端调用高德查询；无法取得结果时会显示重试提示。
- 地图以屏幕中心为准，在当前可视范围内选择最多六条房源，优先一居室、再按距中心的距离排序。可拖动、缩放和筛选；鼠标悬停或手机点击价格可查看房源信息。多个房源位置相近时，价格标签在屏幕上错开并用连线指向原位置，房源坐标不变。
- 房源及坐标为模拟数据，图片为室内示意，不能据此认定真实出租或实际交通情况。地铁线路及站点筛选最终仍受模拟房源原始字段的准确性限制。

## 联系演示

联系方式使用两个独立注册账号演示：先由演示发布方账号进入“联系”并认领模拟房源编号，再由租客账号打开该房源详情，点击“联系房东”。双方可以互发文字，协商时间和地点。认领仅用于演示，不代表真实房东身份；系统不会自动冒充房东回复。

## 本机运行

后端在 `backend` 目录通过 Maven 启动，前端在 `frontend` 目录运行 `npm run dev`。地图配置从本机忽略提交的配置文件读取，不要将密钥提交到版本库。Android Studio 打开 `frontend/android`；前端修改后在 `frontend` 中运行 `npm run android:sync`。

## 当前边界

AI 对话和居住方案仍是本地演示，尚未接入大模型或 Agent；模拟房源没有真实发布方。市域机场线的站点目前未从高德接口取得可确认的结果，该线路会显示加载失败，不能视为完整线路数据。
